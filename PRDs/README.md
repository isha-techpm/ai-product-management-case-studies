## 🧑‍🤝‍🧑 1️⃣ Accredian – Community Hub Feature Plan

**🧩 Context**
Accredian learners were actively using external tools like WhatsApp and Telegram for discussions, which reduced engagement on the platform and fragmented knowledge sharing.

**🚩 Problem Identified**

* Low in-platform engagement
* Conversations scattered across external apps
* Limited visibility and moderation for instructors

**🛠️ What I Worked On**

* Defined a **Community Hub** within Accredian
* Designed sections such as Doubts, Case Studies, Job Prep, and Alumni Insights
* Evaluated build vs buy options (native features vs third-party tools)
* Identified risks like spam, low adoption, and mentor burnout
* Suggested mitigation through moderation rules, gamification, and structured threads

**📦 Key Deliverables**

* Problem statement and product vision
* Feature scope and user flow
* Risks and mitigation strategies

**🎯 Skill Focus**
Product discovery, engagement design, prioritization, trade-off analysis

## 📊 2️⃣ DataSync 360 – Data Observability PRD

**🧩 Context**
Data engineering teams often relied on multiple tools to monitor pipelines, which made debugging slow and outcomes hard to connect to business metrics.

**🚩 Problem Identified**

* No single source of truth for pipeline health
* High Mean Time to Detect (MTTD) and Mean Time to Resolve (MTTR)
* Limited visibility for non-technical stakeholders

**🛠️ What I Worked On**

* Conceptualized **DataSync 360** as a centralized internal observability tool
* Defined personas including data engineers, analysts, and PMs
* Designed dashboards for pipeline health, alerts, and historical trends
* Proposed integrations with Slack, Teams, Jira, and Azure services
* Defined KPIs such as pipeline reliability and issue resolution time

**📦 Key Deliverables**

* Detailed PRD with features, architecture, and roadmap
* Success metrics and risk analysis

**🎯 Skill Focus**
B2B products, internal tools, metrics-driven thinking, technical collaboration

## 💻 3️⃣ Lappyy.com – Refurbished Laptop Marketplace PRD

**🧩 Context**
Lappyy is a refurbished laptop marketplace where buyers preferred enquiry-based interactions over direct online purchases due to trust concerns.

**🚩 Problem Identified**

* Confusing product discovery
* Low trust in refurbished listings
* No visibility into enquiry outcomes

**🛠️ What I Worked On**

* Defined MVP scope centered around product discovery and lead generation
* Designed enquiry flow instead of full checkout
* Improved usability through better categorization and confirmations
* Used Google Analytics to track engagement and enquiry performance

**📦 Key Deliverables**

* MVP-focused PRD
* UX and flow improvements
* Analytics-backed success metrics

**🎯 Skill Focus**
UX thinking, MVP scoping, analytics, freelance stakeholder management

## ✅ 4️⃣ Vendor Verification & Admin Panel Optimization

**🧩 Context**
Vendor onboarding was manual and time-consuming, causing delays and data inconsistency across systems.

**🚩 Problem Identified**

* Offline verification process
* Poor admin efficiency
* Limited mobile usability

**🛠️ What I Worked On**

* Designed an in-dashboard vendor verification workflow
* Added click-to-call and real-time status updates
* Focused on mobile-responsive admin UI
* Used existing database fields to avoid schema changes

**📦 Key Deliverables**

* End-to-end workflow design
* Clear success metrics for verification speed and accuracy
* Risk and trade-off documentation

**🎯 Skill Focus**
Internal tools, process optimization, execution ownership, stakeholder alignment
